## 구성

원자료의 정적인 도표를 **직접 조작 가능한 실험 11개**로 옮겼습니다.

1. **합성곱 실험대** — 3×3 창을 한 칸씩 밀며 9개의 곱셈과 덧셈을 실시간으로 확인. 입력 격자를 클릭해 직접 그림을 바꿀 수 있음
2. **필터 편집기** — 필터 9칸을 직접 수정하며 실제 이미지에 미치는 효과를 즉시 확인 (블러/엣지/윤곽/샤픈/엠보스)
3. **출력 크기 계산기** — W·K·S·P 슬라이더로 `(W−K+2P)/S+1` 공식 체득
4. **맥스 풀링** — 출력 칸에 마우스를 올리면 어느 2×2 영역에서 왔는지 역추적
5. **수용영역** — 층을 쌓을수록 시야가 `2L+1`로 넓어지는 과정
6. **AlexNet 비용 해부** — 메모리/파라미터/연산량 전환 시 봉우리 위치가 완전히 달라지는 것을 시각화
7. **ImageNet 타임라인** — 2010~2017 오류율 막대를 클릭해 그해의 사건 확인
8. **VGG 계산기** — 3×3 두 층 vs 5×5 한 층 파라미터 비교 (`18C²` vs `25C²`)
9. **잔차 블록 토글** — `F(x)=0`으로 만들면 출력이 `x`가 되는 과정
10. **MobileNet 절감 계산기** — 깊이별+화소별 분리의 `9C/(9+C)` 절감 비율
11. **확인 문제 7선** — 원자료 3문항 + 계산 문항 4개, 즉시 채점 및 해설

### 챕터

`왜 배우나` → `FCN vs CNN` → `합성곱` → `필터가 보는 것` → `크기 계산` → `수용영역` → `비용의 3요소` → `모델 변천사(AlexNet→VGG→ResNet→MobileNet)` → `확인 문제` → `부록(용어사전·요약표)`
